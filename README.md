# حسابچی

پایه‌ی اولیه‌ی یک داشبورد فارسی برای مدیریت کسب‌وکارهای کافه و رستوران، بررسی فروش و هزینه‌ها و محاسبه‌ی قیمت تمام‌شده‌ی محصولات.

## اجرا

```bash
npm install
npm run dev
```

نیازمندی اجرا: Node.js نسخهٔ 20.9 یا بالاتر.

سپس `http://localhost:3000` را باز کنید.

## وضعیت فعلی

- داشبورد واکنش‌گرا و راست‌چین با خلاصه فروش، هزینه، سود، نمودار نمونه، ترکیب هزینه‌ها و فهرست محصولات
- بخش جداگانه‌ی مواد اولیه برای ثبت و ویرایش مقدار و قیمت خرید هر بسته، دسته‌بندی، فیلتر و جست‌وجو دارد؛ قیمت هر گرم/میلی‌لیتر/عدد به‌صورت خودکار محاسبه می‌شود.
- تاریخچه‌ی قیمت با تاریخ شمسی ثبت می‌شود؛ فقط قیمت جاری ماده در محاسبه‌ی بهای محصول استفاده می‌شود.
- در دستور پخت محصول می‌توان مقدار مصرف هر ماده را وارد کرد؛ بهای مصرف با قیمت واحد ماده محاسبه و به بهای محصول اضافه می‌شود.
- داده‌های بخش محصولات روی همان مرورگر ذخیره می‌شوند؛ هنوز حساب کاربری یا پایگاه داده وجود ندارد. اعداد داشبورد همچنان نمایشی هستند.
- گام‌های بعدی محصول: مدیریت هزینه‌های ثابت و جاری، حقوق پرسنل، ثبت فروش و گزارش‌های روزانه، ماهانه و سالانه.

## فناوری‌ها

Next.js App Router، React، TypeScript و Tailwind CSS 4.
